Flip Point Calculator

A Bayes Factor Robustness Diagnostic for Thirteen Statistical Tests
Companion to Lovric: The Bayes Factor Reversal Paradox, BJPS 2026

One-sample t-test (JZS prior)

Test H₀: μ = μ₀ versus H₁: μ ≠ μ₀ with the JZS Cauchy(0, r) prior on the standardized effect size.

BF₀₁(t; r, ν) = (1 + t²/ν)-(ν+1)/2 / ∫₀∞ (1 + N·g)-1/2 · (1 + t²/(ν·(1+N·g)))-(ν+1)/2 · π(g) dg
where N = Neff·r², Neff = n, ν = n − 1

Two-sample t-test (JZS prior)

Test H₀: μ₁ = μ₂ versus H₁: μ₁ ≠ μ₂. Standardized effect size δ = (μ₁−μ₂)/σ has Cauchy(0, r) prior.

BF₀₁(t; r, ν) = (1 + t²/ν)-(ν+1)/2 / ∫₀∞ (1 + N·g)-1/2 · (1 + t²/(ν·(1+N·g)))-(ν+1)/2 · π(g) dg
where N = Neff·r², Neff = n₁·n₂/(n₁+n₂), ν = n₁ + n₂ − 2

Paired t-test (JZS prior)

Same JZS framework as one-sample t-test, applied to differences. Neff = n (number of pairs), ν = n − 1.

One-sample z-test (closed form)

Test μ = μ₀ with σ known. The Bayes factor admits a closed form via conjugate normal-normal updating.

BF₀₁(z; k) = √(1+k) · exp(−z²·k/(2(1+k))), where k = n·τ²
Flip point: solve (1+k*)·log(1+k*) = z²·k* (exists iff |z| > 1)

One-way ANOVA (Rouder et al. 2012)

Balanced one-way ANOVA with k groups, n observations per group. Implementation matches BayesFactor R's oneWayAOV.Fstat.

BF₁₀ = ∫₀∞ (1 + N·g)-(J−1)/2 · ω-(NJ−1)/2 · IG(g; 1/2, r²/2) dg
where ω = (1 + N·g/(d·F+1)) / (1+N·g), d = (J−1)/(NJ−J)
Note. This calculator implements the Rouder et al. (2012) / BayesFactor R ANOVA Bayes factor and reproduces the ANOVA flip-point table in the paper.

One-proportion test (Beta-Binomial)

Test H₀: p = p₀ versus H₁: p ≠ p₀ with symmetric Beta(a, a) prior on p under H₁.

BF₀₁(x; a) = p₀x·(1−p₀)n−x / [B(x+a, n−x+a) / B(a, a)]

Two-proportion test (Beta-Binomial)

Test H₀: p₁ = p₂ versus H₁: p₁ ≠ p₂ with independent Beta(a, a) priors on p₁ and p₂ under H₁.

BF₀₁ = [B(x₁+x₂+a, n₁+n₂−x₁−x₂+a)/B(a,a)] / { [B(x₁+a, n₁−x₁+a)/B(a,a)] · [B(x₂+a, n₂−x₂+a)/B(a,a)] }

Correlation test (Ly, Verhagen & Wagenmakers 2016)

Test H₀: ρ = 0 versus H₁: ρ ≠ 0. Stretched-beta prior on ρ with paper's concentration parameter κ.

π(ρ; κ) ∝ (1 − ρ²)κ−1 on (−1, 1)
Note. This calculator implements the Ly et al. (2016) stretched-beta correlation Bayes factor and reproduces the correlation flip-point table in the paper. κ is the concentration parameter of the stretched Beta(κ, κ) prior; larger κ concentrates mass near ρ = 0.

Simple linear regression

Test H₀: β = 0 in a single-predictor regression. Equivalent to one-sample t-test on the slope, with ν = n − 2.

Omnibus regression test (Liang et al. 2008)

Test H₀: all slopes zero in multiple regression. Implementation matches BayesFactor R's linearReg.R2stat.

Note. This calculator implements the Liang et al. (2008) / BayesFactor R $g$-prior omnibus Bayes factor and reproduces the multiple-regression flip-point table in the paper.

Chi-squared independence test (Gunel & Dickey 1974)

Test independence in an R × C contingency table with Dirichlet(a, ..., a) prior structure.

Mann-Whitney test (van Doorn et al. 2020, approximate)

Bayesian rank-based test for two independent groups. Tests H₀: P(X > Y) = 1/2.

Note. This is an approximate implementation using the asymptotic rank-statistic distribution. For exact rank-likelihood Bayes factors, use the BayesianMW R package by van Doorn et al.

About this calculator

This tool implements the flip-point methodology described in:

Lovric, M.M. (2026). The Bayes Factor Reversal Paradox: A Unified Theory Across Statistical Tests. Brazilian Journal of Probability and Statistics.

The flip point

For each test, the flip point is the unique prior scale at which BF₀₁ = 1. Below the flip point, evidence favours H₁; above, it favours H₀. The flip point summarizes the prior-sensitivity of a Bayesian conclusion in a single diagnostic value.

Implementation notes

  • Parametric tests reproduce the paper's tables: the z-test, all t-tests (one-sample, two-sample, paired), one-way ANOVA, one- and two-proportion tests, correlation, and simple and multiple regression reproduce the corresponding published flip-point tables, and use the canonical Bayes factor references (Rouder et al. 2009, 2012 for t-tests and ANOVA; Liang et al. 2008 for regression; Gunel & Dickey 1974 for contingency tables; Ly et al. 2016 for correlation).
  • Mann-Whitney: approximate via the rank-statistic asymptotic distribution. For exact computation see van Doorn et al. (2020) and the BayesianMW package.
